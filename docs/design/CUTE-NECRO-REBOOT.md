# CUTE NECRO REBOOT — active visual direction

Founder direction: bright, cute, original chibi fantasy. The old Obsidian Soul direction is historical only.

## Active rules
- 2.0–2.5 head chibi proportion; large readable head/face, short limbs.
- Friendly toy/storybook fantasy rather than horror, gore, photoreal cemetery, or large black surfaces.
- Cream field with mint / sky / violet / coral / yellow accents.
- Enemies should look desirable as future companions.
- Raise fantasy is presented emotionally as making a spirit friend, while existing combat/domain mechanics remain unchanged.
- Specific third-party characters, silhouettes, costumes, color layouts, UI or assets are not copied.

## Content target
- 120 planned unique character slots.
- 12 families × 10 characters.
- Shared rig/skeleton is allowed, but each character requires distinct silhouette, face, prop, palette treatment and skill VFX identity.
- Current representative slice contains only prototype/candidate character art; 120 finished release illustrations are NOT claimed.
